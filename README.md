# CCNA Network Security Course

Personal learning repository documenting my progress through Cisco NetAcad's **Network Security** course, part of my specialization path in DevOps/NetDevOps and Cybersecurity.

## 📋 Overview

This repository serves as a structured knowledge log and practical portfolio for the *Network Security* course. Each topic covered in the course is documented in its own Markdown file, containing key concepts, commands, notes, and — where applicable — a hands-on mini-project that applies the topic's concepts in practice.

The goal of this repository is twofold:
1. Reinforce theoretical understanding through written documentation.
2. Translate that theory into working code/configurations via small applied projects.

## 🎯 Learning Objectives

- Understand core network security principles: confidentiality, integrity, and availability (CIA triad).
- Apply cryptographic concepts (symmetric/asymmetric encryption, hashing, key exchange) to real scenarios.
- Configure device hardening measures (login security, ACLs, authentication policies) on network equipment.
- Build small applied tools that reinforce each topic through code.
